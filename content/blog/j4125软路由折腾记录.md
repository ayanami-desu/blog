首先就是用U盘启动，这里不详述。

要像N1那样写入emmc将系统写入到硬盘的方法我没有找到。不过有类似的。就是将系统镜像通过dd命令刷入到硬盘。这也是在linux下制作启动盘的方法。

```
dd if=/tmp/op.img of=/dev/sda
```

同时附上格式化硬盘的命令。

```
#此命令为常规强制格式化命令，禁用 root 保留分区，并使用默认的 inode 数，适合存放海量零碎的小文件。
mkfs.ext4 -F -m 0 /dev/sda
```

对于系统刷好后对分区扩容的问题。这里使用和网上不同的方法。（感谢群友）。

将剩余空间格式化为新分区，在挂载点设置中把新分区挂载到/opt/docker。

![](/wp-content/uploads/2024/04/image-1024x320.png)

要使用什么包跑docker就好了。大文件的暂存也可以放在/opt/docker下。
